UniVLA 的 latent action 怎样从视频迁移到机器人？

专项资料归档：机器人视觉动作训练。后端与 Agent 面试主线不展开此专项，完整内容保留供按需查阅。

本质前后帧用于构造潜在动作标签，在线策略只看当前可见信息；设备解码器仍需机器人数据与控制校验。

25. UniVLA 的 latent action 到底是什么？

常见问法： 没有机器人动作标签的视频怎么训练策略？为什么用 DINO 特征？latent action 如何变成真实动作？

面试回答： UniVLA 先从视频变化中学习任务相关的离散潜在动作，再训练视觉语言策略预测这些潜在动作，最后用机器人侧解码器把它们变成可执行控制。

这里是 latent action，即潜在动作，不是“延迟动作”。它描述的是两段观察之间对任务有用的变化，不一定等于某个固定关节角增量。因此不同设备的视频可以在更抽象的表示上共享知识。

如果只重建原始像素，潜变量可能忙着解释相机抖动、光照和背景变化。UniVLA 利用 DINOv2 特征并结合语言任务信息，区分任务相关与无关变化，再用量化码表示潜在动作。后续策略根据当前观察和指令预测这些 token，而不是在部署时偷看未来帧。

潜在动作模型怎样具体搭建？ 用间隔已知的前后帧构造逆动力学编码器 IDM，从两帧的 DINOv2 patch 特征提取变化，再量化成码本索引；重建端学习预测未来 DINO 特征，避免把大量容量花在像素纹理。监督标签构建可以读取未来帧，在线策略不能。

UniVLA 的任务解耦分两步。第一步给编码器与解码器语言条件，让任务语义已有单独通道，受限潜码主要捕获剩余的任务无关变化。第二步保留并冻结已有任务无关码本，再增加任务相关潜码，让新码承担缺失的任务变化。这里的“相关/无关”是模型训练目标，不是保证所有背景变化都能被完美剔除。

后续通用策略基于 Prismatic-7B 视觉语言骨干预测这些离散动作 token；机器人部署侧还有把潜在动作翻译到具体控制空间的解码器。视觉语言骨干、潜在动作编码/量化模型、设备动作解码器是不同模块，不能把某段项目口述的“7B”或“1–2B”无条件分配给所有模块，也不能说两次适配必然训练同一个 7B 网络。

为什么训练时可以看前后帧，推理时不行？ 前后帧用于产生监督标签；部署策略只接收当时可获得的观察与指令。把用于标签构建的未来帧混进在线输入，会发生信息泄漏。

没有动作标签是不是完全不需要机器人数据？ 不是。视频预训练降低了对大规模动作标注的依赖，但要在某个机器人上执行，仍需要把潜在动作映射到该设备的控制空间，适配解码器并验证行为。潜在 token 不会自动变成所有机器人的通用控制协议。

数据怎么做？ 明确任务片段起止、指令、采样间隔与相机视角；不同帧率的视频要对齐时间含义。跨场景划分评测集，避免相邻帧泄漏。报告规模时区分视频小时数、轨迹数、动作标签数和有效成功任务数，不能只说收集了很多条。
