- 根目录的 `index.html`、`assets/`、`data/`、`project/`：已构建的网站，供现有 GitHub Pages 配置直接发布。
- `site/`：完整维护源码、原始兼容基线与回归测试。新增题目主要编辑 `site/authoring/`，不要直接编辑生成的网页。
- `site/baseline/`：最初单文件网站的只读快照；原始提交也保留在 Git 历史。

## 本地预览与修改

需要 Node.js 20 或以上，无第三方 npm 依赖，不需要 `npm install`。

```sh
cd site
npm run build
npm run serve
```

打开 http://localhost:4173/notes-58c0/ 。不要直接双击 HTML，章节与搜索索引通过 HTTP 按需加载。

维护方式、稳定 ID 和新增题目说明见 [源码维护指南](site/README.md) 和 [字段指南](site/authoring/README.md)。

## 更新线上内容

在仓库根目录运行：

```sh
node scripts/prepare-pages.mjs
```

该命令先从 `site/` 构建，再将构建产物同步到根目录。它不执行 Git 提交、推送或修改 Pages 设置。审阅差异、运行相关测试后再自行提交推送。GitHub Pages 沿用当前 main 分支根目录发布。
