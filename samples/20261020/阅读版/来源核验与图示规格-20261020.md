## 图示制作规格（可渲染 SVG）

标题：RAG 的两条链路与两层评测

建议画布：宽 1400，高 880；中文无衬线字体；顶部离线链浅蓝，中央在线链浅绿，底部评测带浅紫。权限与失败路径橙色。节点每行最多 3 行，所有箭头明确指向。

A. 离线链，左至右五节点：
1. 原始资料 / 正文·版本·权限
2. 解析与分块 / 保留结构和限定
3. 元数据 + 双索引 / 关键词·向量
4. 校验与切换版本 / 更新·删除·撤权
5. 可检索快照 / 索引版本可追踪

B. 在线链，两行：
第一行左至右：用户问题 + 认证身份 → 权限约束召回 → 融合去重 → 重排。
第二行从重排向下，再从右至左：上下文组装 → 生成 + 引用 → 支持与边界检查 → 回答 / 澄清 / 证据不足。
离线“可检索快照”以向下箭头接在线“权限约束召回”。
在权限约束召回旁放标注：“未经授权原文不能进入模型”。
在重排旁放标注：“只能处理已召回候选”。
上下文组装旁放标注：“版本 + 来源 + token 预算”。

C. 两层评测底带：
检索层：证据有没有找到？是否排在前面？Recall@k / MRR / nDCG。
回答层：是否正确完整？证据是否支持主张？事实覆盖 / 有据主张 / 引用支持。
中间一条强调语：“检索满分 ≠ 回答正确”。

D. 贯穿标记与失败路径：
图边缘注明：“全链：身份、版本、预算、trace；检索内容是数据，不是指令”。
权限未知从召回接橙色“停止读取”；证据不足从上下文接“澄清 / 拒绝确定结论”；版本冲突从检查接“展示冲突”。不要把失败路径画成无标注的成功回答。

图替代文本：离线资料经解析分块、元数据与索引构建、校验切换后支持在线授权检索。在线请求经过召回、融合、重排、上下文组装、带引用生成和支持关系检查。权限、证据不足和版本冲突分别有失败处理，检索层和回答层独立评测。
